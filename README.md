## About

I'm a software engineer working mostly on the backend: APIs, databases, authentication and the logic that connects them. When a feature needs a screen, I build that part too.

Day to day I write Node.js and TypeScript, model data in PostgreSQL and MongoDB, and use React with Tailwind CSS on the frontend. I like well-structured databases, readable code and solving the logic problems that show up between the database and the user.

Lately I've been learning more about cloud services and using AI tools in my own workflow.

## What I work on

- **Backend Engineering:** REST APIs, business logic, services, and application architecture.
- **Database Engineering:** Data modeling, relational database design, and query optimization.
- **Authentication & Security:** Authentication, authorization, access control, and secure integrations.
- **System Integration:** Third-party APIs, payment services, messaging platforms, and external systems.
- **Full Stack Development:** React and TypeScript interfaces integrated with backend services.
- **Software Architecture:** Code organization, design patterns, maintainability, and scalable application structures.
